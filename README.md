# Desenvolvimento_Web_DotNet
Material de apoio curso de Análise e Desenvolvimento Unip Sorocaba

## Conteúdo
- [1 - HTML básico](1%20-%20html%20basico/README.md): introdução e exemplos básicos de HTML.
- [2 - HTML componentes básicos](2%20-%20html%20componentes%20basicos/README.md): página de login em HTML puro com formulário, campos de entrada e botão.
- [3 - HTML estilos básico](3%20-%20html%20estilos%20basico/README.md): página de login com estilos inline, alinhamento central e aparência mais agradável.
- [4 - HTML estilos style](4%20-%20html%20estilos%20style/README.md): página de login com estilos definidos na tag style, usando seletores e propriedades CSS básicas.
- [5 - HTML CSS](5%20-%20html%20css/README.md): página de login com CSS separado em arquivo próprio, mostrando uma organização mais profissional do projeto.
- [6 - HTML CSS seletores](6%20-%20html%20css%20seletores/README.md): uso de seletores CSS como classe, descendente, atributo e pseudo-classes para estilizar a página com mais precisão.
- [7 - HTML JS validação](7%20-%20html%20js%20validacao/README.md): página de login com validação em JavaScript, verificando nome e senha antes de permitir acesso.
- [8 - HTML CSS JS separados](8%20-%20html%20css%20js%20separados/README.md): mesma lógica do exercício 7, porém com HTML, CSS e JavaScript organizados em arquivos distintos.
- [9 - ASP.NET WebForm](9%20-%20ASP%20dotNet%20WebForm/README.md): mesma tela de login do exercício 8, com validação server-side em ASP.NET Core Razor Pages.
- [10 - ASP.NET Core MVC](10%20-%20ASP%20dotNet%20mvc/README.md): mesma tela de login, com validação server-side e separação entre Controller, Model e View.
- [11 - ASP.NET Core Web API](11%20-%20%20ASP%20dotNet%20WebAPI/README.md): mesma regra de login exposta como endpoint HTTP que recebe e devolve JSON.
- [12 - ASP.NET Core Blazor](12%20-%20ASP%20dotNet%20Blazor/README.md): mesma regra de login em um componente Razor interativo (Blazor Server), com `EditForm` e validação no servidor.
- [13 - HTML JS consumindo Web API](13%20-%20html%20js%20consumindo%20webapi/README.md): cliente HTML/CSS/JS tradicional que consome, via `fetch`, o endpoint JSON do exercício 11.
